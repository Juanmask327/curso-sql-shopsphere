# Introducción — Nivel 0: Antes de escribir la primera query

Antes de responder cualquier pregunta, necesitas saber con qué estás trabajando.

ShopSphere tiene años de datos acumulados: transacciones, clientes, productos, campañas, devoluciones, pagos fallidos. El problema no es la cantidad de información — es que nadie la ha leído de forma sistemática. Esa es exactamente tu función a partir de hoy.

En este nivel no vas a analizar nada todavía. Vas a orientarte. Aprenderás a navegar la base de datos de ShopSphere: qué tablas existen, cómo están organizadas, cuántos registros tiene cada una y qué período cubre la información. Es el equivalente a llegar a una ciudad nueva y conseguir el mapa antes de salir a caminar.

Este trabajo de orientación importa más de lo que parece. Un analista que no sabe qué datos tiene disponibles termina respondiendo preguntas incompletas o, peor, respondiendo preguntas equivocadas con mucha confianza.

Al terminar este nivel sabrás responder la pregunta que Valentina ya te hizo en tu primer día: ¿qué tenemos en la base de datos y con qué estamos trabajando? Es una pregunta sencilla. La respuesta correcta es la base de todo lo que viene después.
